# Knorr Force for Good Champions

A vanilla HTML, CSS, and JavaScript campaign site prototype for the Knorr Green Food Steps community activation.

## Run locally

Open `index.html` directly, or serve the folder with any static web server.

## Scope

The current prototype includes the public campaign home page, responsive navigation, light and dark mode, the three Green Food Steps, champion journey UI, video embeds, impact highlights, and a registration flow preview without authentication or persistence.

## GitHub Pages

The site deploys automatically from the `main` branch using the workflow in `.github/workflows/deploy-pages.yml`.
